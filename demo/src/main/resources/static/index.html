Demonstrasi integrasi Model Bisnis BPMN 2.0 dengan Java J2EE / Jakarta Framework menggunakan Spring Boot & Camunda Process Engine.

📊 Camunda Cockpit 📋 Camunda Tasklist 🧪 Test Hello World API 🗄️ H2 Database Console
📝 Form Pengajuan Cuti (Start Event)
*Aturan: Cuti ≤ 2 hari otomatis disetujui sistem; Cuti > 2 hari butuh review Manajer.
🔄 Alur Proses Bisnis BPMN 2.0
1
Start Event: Pengajuan Cuti Diajukan
Karyawan mengisi data permohonan melalui form web atau REST API.
2
Service Task: Validasi & Cek Aturan Bisnis
Spring Bean (ValidasiCutiDelegate) memeriksa durasi cuti secara otomatis.
3
Exclusive Gateway (XOR): Evaluasi Syarat
• Jika ≤ 2 Hari → Auto-Approve langsung ke notifikasi.
• Jika > 2 Hari → Diteruskan ke User Task Manajer.
4
User Task: Persetujuan Manajer
Manajer dapat menyetujui atau menolak permohonan melalui Camunda Tasklist atau Web UI ini.
5
Service Task & End Event: Notifikasi & Selesai
Mengeksekusi NotifikasiDisetujuiDelegate atau NotifikasiDitolakDelegate dan menyimpan status akhir.
